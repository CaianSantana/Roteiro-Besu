# Hyperledger Besu QBFT Private Network
Ambiente completo de laboratório para provisionamento, configuração e operação de uma rede blockchain permissionada Ethereum-compatible baseada em Hyperledger Besu com consenso QBFT (Quorum Byzantine Fault Tolerance), integração com carteira digital (MetaMask) e ciclo de vida de contratos inteligentes via Remix IDE.
